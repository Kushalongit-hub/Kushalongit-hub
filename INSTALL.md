# Installation

1. Create a **public** GitHub repository named `Kushalongit-hub` under the account `Kushalongit-hub`.
2. Upload `README.md` and the `assets/` directory to its root.
3. Commit. The README appears on your GitHub profile.

Images are local SVGs: no external image hosts, fonts, tracking scripts, or third-party stats APIs. All contact and portfolio links are editable in `README.md`. Some browsers or GitHub modes may disable SVG animations; the still image remains readable.

The OpenConnect, MESH, and Bedrock links are GitHub repository search links rather than unverified exact repository paths. Replace them with direct links if you wish.
